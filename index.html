AI flashcard maker

Let your AI build the deck

Tell your AI what you want to learn, from the show you love to next week’s interview, or hand it your notes. Pick an idea, make it yours, and paste it into Claude, ChatGPT, Gemini or the agent you already use.

  • Hand it anything: a PDF, slides, a spreadsheet or a photo of your notes.
  • Works in the AI app you already use, on your computer or in the browser.
  • You approve the sign-in on your phone, and it only touches your decks.

Using Claude Code or Codex?

Install the Loopky plugin once. Then just ask for flashcards: it knows every step, and on Claude Code on the web it installs the CLI itself.

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky

Build me a Loopky flashcard deck with the Loopky CLI.
