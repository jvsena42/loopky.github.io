Funciona onde sua IA funciona

No app de IA que você já usa, no computador ou no navegador. Nada para você instalar.

O prompt

Cole isto na sua IA e preencha o tema ou anexe um arquivo. Você aprova o login no celular.

Prompt para sua IA 
Build me a Loopky flashcard deck with the Loopky CLI.

Topic: <WHAT I WANT TO LEARN>
Cards: <HOW MANY>

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1

Claude Code e Cursor abrem com o prompt preenchido. Codex e Jules abrem vazios: o prompt é copiado, é só colar.

Depois é só estudar no celular

O baralho aparece no Loopky, pronto para a repetição espaçada, com áudio nos baralhos de idiomas. Revise as cartas escritas por IA para achar erros.

Nada para você instalar

Sua IA instala o Loopky sozinha, no Windows, macOS ou Linux, até quando você conversa com ela pelo navegador. Homebrew, pacote .deb e Docker também funcionam.

Perguntas

Preciso saber programar?

Não. Cole o prompt na sua IA, junte o tema ou o arquivo, e ela faz todos os passos sozinha. Funciona em apps de chat com IA e em agentes como Claude Code, Codex e Gemini CLI.

Existe um plugin para Claude Code ou Codex?

Sim. No Claude Code, rode /plugin marketplace add jvsena42/loopky e depois /plugin install loopky@loopky. No Codex, rode codex plugin marketplace add jvsena42/loopky e depois codex plugin add loopky@loopky. Depois é só pedir flashcards: o plugin conhece cada passo, então você não precisa de prompt.

A IA pode importar meus baralhos do Anki?

Sim. loopky import deck.apkg importa um pacote do Anki, e --dry-run mostra o resultado antes.

O que a ferramenta não faz?

Ela não posta, não segue pessoas e não edita seu perfil. Só gerencia baralhos e cartas.

Funciona no Claude Code na web ou no Codex?

Sim, depois que o sandbox conseguir acessar os hosts do Loopky. Nenhum dos dois libera por padrão. Peça para o agente rodar loopky doctor: ele lista os hosts e onde adicioná-los. No Codex, deixe desligada a opção só GET/HEAD/OPTIONS. Com o plugin, o Claude Code na web instala a CLI sozinho. Um sandbox que inspeciona TLS funciona depois que o certificado dele é indicado em SSL_CERT_FILE.

Que arquivos ela transforma em cartas?

Tudo o que a sua IA consegue ler: PDFs, arquivos do Word e PowerPoint, planilhas, fotos de anotações, legendas e páginas da web.
