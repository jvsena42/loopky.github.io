Criador de flashcards com IA

Deixe sua IA montar o baralho

Diga para a sua IA o que você quer aprender, da série que você ama à entrevista da semana que vem, ou entregue suas anotações. Escolha uma ideia, ajuste do seu jeito e cole no Claude, ChatGPT, Gemini ou no agente que você já usa.

  • Entregue qualquer coisa: um PDF, slides, uma planilha ou a foto das suas anotações.
  • Funciona no app de IA que você já usa, no computador ou no navegador.
  • Você aprova o login no celular, e ela só mexe nos seus baralhos.

Usa Claude Code ou Codex?

Instale o plugin do Loopky uma vez. Depois é só pedir flashcards: ele conhece cada passo e, no Claude Code na web, instala a CLI sozinho.

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky

Prompt para sua IA

Comece por uma ideia

Ao copiar, entram os passos de instalação, para a sua IA instalar o Loopky, escrever as cartas e publicar o baralho.

Ver o prompt completo 
Build me a Loopky flashcard deck with the Loopky CLI.

What I want:
Um baralho de japonês com 40 palavras e frases da primeira temporada de Naruto. Kanji na frente, leitura e significado no verso.

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1
Abrir em

Claude Code e Cursor abrem com o prompt preenchido. Codex e Jules abrem vazios: o prompt é copiado, é só colar.
