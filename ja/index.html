アプリで学ぶ

AI 単語カードメーカー

AI にデッキを作らせる

ハマっているドラマから来週の面接まで、覚えたいことを AI に伝えるか、ノートをそのまま渡しましょう。アイデアを選んで自分好みに直し、Claude、ChatGPT、Gemini やいつも使っているエージェントに貼り付けるだけです。

  • PDF、スライド、表計算、ノートの写真など、何でも渡せます。
  • いつもの AI アプリで、パソコンでもブラウザでも動きます。
  • ログインはスマートフォンで承認。触れるのはあなたのデッキだけです。

Claude Code や Codex を使っていますか？

Loopky プラグインを一度インストールすれば、あとはフラッシュカードを頼むだけ。手順はすべて把握しており、Web 版 Claude Code では CLI も自動でインストールします。

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky

アイデアから始める

コピーするとセットアップ手順も付くので、AI が Loopky をインストールし、カードを書いてデッキを公開します。

プロンプト全文を見る 
Build me a Loopky flashcard deck with the Loopky CLI.

What I want:
「千と千尋の神隠し」英語吹き替え版から、英単語とフレーズ 40 個のデッキを作って。表に英語、裏に意味と使われた場面。

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1
AIで開く

Claude Code と Cursor はプロンプトが入力された状態で開きます。Codex と Jules は空で開くので、コピーされたプロンプトを貼り付けてください。
