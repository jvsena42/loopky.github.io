loopky
# Your AI agent runs these for you
$ loopky login
$ loopky deck create --title "Spanish verbs" \
    --from-file cards.tsv --dry-run --json
$ loopky deck create --title "Spanish verbs" \
    --tag spanish --from-file cards.tsv \
    --front-lang es-ES --back-lang en-US --listen --speak

よくある質問

プログラミングの知識は必要ですか？

いいえ。プロンプトを AI に貼り付けて、トピックかファイルを渡せば、あとは AI がすべて進めます。AI チャットアプリや、Claude Code、Codex、Gemini CLI などのエージェントで使えます。

Claude Code や Codex 用のプラグインはありますか？

はい。Claude Code では /plugin marketplace add jvsena42/loopky を実行してから /plugin install loopky@loopky を実行します。Codex では codex plugin marketplace add jvsena42/loopky を実行してから codex plugin add loopky@loopky を実行します。あとは単語カードを頼むだけ。プラグインが手順をすべて把握しているので、プロンプトは不要です。

AI は Anki デッキを取り込めますか？

はい。loopky import deck.apkg で Anki パッケージを取り込めます。--dry-run を付けると先に結果を確認できます。

このツールにできないことは？

投稿、フォロー、プロフィール編集はできません。管理するのはデッキとカードだけです。

Claude Code on the web や Codex でも使えますか？

はい。サンドボックスから Loopky のホストに接続できれば使えます。どちらも初期設定では許可されていません。エージェントに loopky doctor を実行させると、必要なホストと追加する場所が表示されます。Codex では「GET/HEAD/OPTIONS のみ」の設定をオフのままにしてください。プラグインがあれば、Web 版 Claude Code は CLI を自動でインストールします。TLS を検査するサンドボックスも、その証明書を SSL_CERT_FILE で指定すれば動きます。

どんなファイルをカードにできますか？

AI が読めるものなら何でも。PDF、Word や PowerPoint のファイル、表計算、ノートの写真、字幕、Web ページなど。
