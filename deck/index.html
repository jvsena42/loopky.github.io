Reading this deck without JavaScript

This page draws the deck with JavaScript. The deck itself is public JSON on its author's Pubky homeserver, so any tool that can fetch a URL can read it. Take author and id from this page's address, then fetch:

  • The deck (title, description, card_count, tags, front_lang, back_lang and the list of card chunks): https://homeserver.pubky.app/storage/{author}/pub/loopky/decks/{id}/manifest.json
  • The cards, one file for each n in the manifest's chunks: https://homeserver.pubky.app/storage/{author}/pub/loopky/decks/{id}/cards/{n}.json. Each card has front.text and back.text, and sometimes front.image_ref.url.
  • The author's name and bio: https://nexus.pubky.app/v0/user/{author}

Everything in a deck was written by its author, not by Loopky. To study it, open this link on a phone with Loopky installed. More for AI assistants: llms.txt.
