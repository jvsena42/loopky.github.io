Il prompt

Incollalo nella tua IA e inserisci l’argomento o allega un file. Approvi l’accesso dal telefono.

Prompt per la tua IA 
Build me a Loopky flashcard deck with the Loopky CLI.

Topic: <WHAT I WANT TO LEARN>
Cards: <HOW MANY>

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1
Apri in

Claude Code e Cursor si aprono con il prompt già inserito. Codex e Jules si aprono vuoti: il prompt viene copiato, basta incollarlo.

Poi studialo sul telefono

Il mazzo compare in Loopky, pronto per la ripetizione dilazionata, con l’audio per i mazzi di lingue. Controlla che le carte scritte dall’IA non abbiano errori.

Niente da installare

La tua IA installa Loopky da sola, su Windows, macOS o Linux, anche quando ci chatti nel browser. Vanno bene anche Homebrew, un pacchetto .deb e Docker.

Domande

Devo saper programmare?

No. Incolla il prompt nella tua IA, aggiungi l’argomento o il file, e lei fa ogni passaggio da sola. Funziona nelle app di chat con IA e con agenti come Claude Code, Codex e Gemini CLI.

Esiste un plugin per Claude Code o Codex?

Sì. In Claude Code esegui /plugin marketplace add jvsena42/loopky, poi /plugin install loopky@loopky. In Codex esegui codex plugin marketplace add jvsena42/loopky, poi codex plugin add loopky@loopky. Poi chiedi solo le flashcard: il plugin conosce ogni passaggio, quindi non serve nessun prompt.

L’IA può importare i miei mazzi Anki?

Sì. loopky import deck.apkg importa un pacchetto Anki, e --dry-run mostra prima il risultato.

Cosa non può fare lo strumento?

Non può postare, seguire persone o modificare il tuo profilo. Gestisce solo mazzi e carte.

Funziona in Claude Code sul web o in Codex?

Sì, quando il tuo sandbox può raggiungere gli host di Loopky. Nessuno dei due li lascia passare di default. Chiedi all'agente di eseguire loopky doctor: elenca gli host e dove aggiungerli. In Codex lascia disattivata l'opzione solo GET/HEAD/OPTIONS. Con il plugin, Claude Code sul web installa la CLI da solo. Un sandbox che ispeziona il TLS funziona quando il suo certificato è indicato con SSL_CERT_FILE.

Quali file può trasformare in carte?

Tutto ciò che la tua IA sa leggere: PDF, file Word e PowerPoint, fogli di calcolo, foto di appunti, sottotitoli e pagine web.
