Manage decks from your computer

The Loopky command line tool runs on Windows, macOS and Linux.

  • Create, edit and delete decks
  • Add, edit and remove cards in bulk
  • Import .apkg and TSV files from disk
  • Script it, or let an AI agent do it
loopky
# Bring a whole Anki deck across
$ loopky import deck.apkg --dry-run --json
$ loopky import deck.apkg --title "Pharmacology"
# Or build one from a spreadsheet
$ loopky deck create --title "Verbs" --from-file cards.tsv
$ loopky deck list --json

Move a deck in a minute

In Anki, export the deck as .apkg with media. Open it in Loopky and pick the front and back fields. Only have a list? Paste it.

Questions

Can Loopky fully replace Anki?

For most learners, yes. Check first if you rely on audio files, LaTeX, custom card templates or FSRS.

Does Loopky use FSRS?

No. Each grade button has a fixed interval that you set, from 1 to 365 days.

Is it free?

Yes. No ads, no subscription, and open source under the MIT license.

Is there an iPhone app?

Loopky is on Android now. The iOS app is built and coming soon.
