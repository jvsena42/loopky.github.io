平板和電腦

平板上是雙欄版面，電腦上有命令列工具可批次處理牌組。

為大螢幕而設計

在平板上，Loopky 使用真正的雙欄版面：今天的複習佇列在牌組旁邊，牌組在它的卡片旁邊。現在支援 Android 平板，iOS 應用程式推出後支援 iPad。

在電腦上管理牌組

Loopky 命令列工具可在 Windows、macOS 和 Linux 上執行。

  • 建立、編輯和刪除牌組
  • 批次新增、編輯和移除卡片
  • 從本機匯入 .apkg 和 TSV 檔案
  • 寫成腳本，或交給 AI 代理來做
loopky
# Bring a whole Anki deck across
$ loopky import deck.apkg --dry-run --json
$ loopky import deck.apkg --title "Pharmacology"
# Or build one from a spreadsheet
$ loopky deck create --title "Verbs" --from-file cards.tsv
$ loopky deck list --json

常見問題

Loopky 能完全取代 Anki 嗎？

對大多數學習者來說可以。如果你依賴音訊檔案、LaTeX、自訂卡片範本或 FSRS，請先確認一下。

Loopky 使用 FSRS 嗎？

不使用。每個評分按鈕有固定的間隔，由你設定，範圍是 1 到 365 天。

是免費的嗎？

是的。沒有廣告，沒有訂閱，並以 MIT 授權開源。

有 iPhone 應用程式嗎？

Loopky 現在支援 Android。iOS 應用程式已經做好，即將推出。
