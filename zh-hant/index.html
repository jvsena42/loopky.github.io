AI 記憶卡製作

讓你的 AI 來建牌組

告訴你的 AI 想學什麼，從追的劇到下週的面試都行，也可以直接把筆記交給它。選一個點子，改成你想要的，貼給 Claude、ChatGPT、Gemini 或你常用的代理。

  • 什麼都能交給它：PDF、投影片、試算表或筆記照片。
  • 在你常用的 AI 應用裡就能用，電腦或瀏覽器都行。
  • 登入由你在手機上確認，它只動你的牌組。

在用 Claude Code 或 Codex？

安裝一次 Loopky 外掛，之後直接要字卡就行：它知道每一步，在網頁版 Claude Code 中還會自動安裝 CLI。

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky
