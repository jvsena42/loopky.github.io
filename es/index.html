Creador de flashcards con IA

Deja que tu IA arme el mazo

Dile a tu IA qué quieres aprender, desde la serie que te encanta hasta la entrevista de la semana que viene, o pásale tus apuntes. Elige una idea, hazla tuya y pégala en Claude, ChatGPT, Gemini o el agente que ya usas.

  • Dale lo que sea: un PDF, diapositivas, una hoja de cálculo o una foto de tus apuntes.
  • Funciona en la app de IA que ya usas, en tu computadora o en el navegador.
  • Apruebas el inicio de sesión en tu teléfono, y solo toca tus mazos.

¿Usas Claude Code o Codex?

Instala el plugin de Loopky una vez. Después solo pide flashcards: conoce cada paso y, en Claude Code en la web, instala la CLI por sí solo.

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky

Prompt para tu IA

Empieza con una idea

Al copiar se añaden los pasos de instalación, para que tu IA instale Loopky, escriba las tarjetas y publique el mazo.

Ver el prompt completo 
Build me a Loopky flashcard deck with the Loopky CLI.

What I want:
Un mazo de japonés con 40 palabras y frases de la primera temporada de Naruto. Kanji delante, lectura y significado detrás.

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1
Abrir en

Claude Code y Cursor se abren con el prompt ya escrito. Codex y Jules se abren vacíos: el prompt se copia, solo pégalo.
