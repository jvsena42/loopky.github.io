Funciona donde funciona tu IA

En la app de IA que ya usas, en tu computadora o en el navegador. No tienes que instalar nada.

El prompt

Pega esto en tu IA y completa el tema o adjunta un archivo. Tú apruebas el inicio de sesión en tu teléfono.

Prompt para tu IA 
Build me a Loopky flashcard deck with the Loopky CLI.

Topic: <WHAT I WANT TO LEARN>
Cards: <HOW MANY>

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1
Abrir en

Claude Code y Cursor se abren con el prompt ya escrito. Codex y Jules se abren vacíos: el prompt se copia, solo pégalo.

Luego estúdialo en tu teléfono

El mazo aparece en Loopky, listo para la repetición espaciada, con audio en los mazos de idiomas. Revisa si las tarjetas escritas con IA tienen errores.

Nada que instalar

Tu IA instala Loopky por su cuenta, en Windows, macOS o Linux, incluso cuando chateas con ella en el navegador. También sirven Homebrew, un paquete .deb y Docker.

Preguntas

¿Necesito saber programar?

No. Pega el prompt en tu IA, añade tu tema o archivo, y ella hace cada paso sola. Funciona en apps de chat con IA y en agentes como Claude Code, Codex y Gemini CLI.

¿Hay un plugin para Claude Code o Codex?

Sí. En Claude Code, ejecuta /plugin marketplace add jvsena42/loopky y luego /plugin install loopky@loopky. En Codex, ejecuta codex plugin marketplace add jvsena42/loopky y luego codex plugin add loopky@loopky. Después solo pide flashcards: el plugin conoce cada paso, así que no necesitas prompt.

¿La IA puede importar mis mazos de Anki?

Sí. loopky import deck.apkg importa un paquete de Anki, y --dry-run muestra antes el resultado.

¿Qué no puede hacer la herramienta?

No puede publicar, seguir a personas ni editar tu perfil. Solo gestiona mazos y tarjetas.

¿Funciona en Claude Code en la web o en Codex?

Sí, cuando tu sandbox pueda llegar a los hosts de Loopky. Ninguno de los dos los deja pasar por defecto. Pide al agente que ejecute loopky doctor: lista los hosts y dónde añadirlos. En Codex, deja desactivada la opción de solo GET/HEAD/OPTIONS. Con el plugin, Claude Code en la web instala la CLI por sí solo. Un sandbox que inspecciona TLS funciona cuando su certificado se indica con SSL_CERT_FILE.

¿Qué archivos puede convertir en tarjetas?

Todo lo que tu IA pueda leer: PDFs, archivos de Word y PowerPoint, hojas de cálculo, fotos de apuntes, subtítulos y páginas web.
