AI flashcard maker

Let your AI write the flashcards

Loopky has a command line tool made for AI agents. Tell Claude, ChatGPT, Gemini or any agent with a shell what you want to learn, and it writes the cards and publishes the deck to your phone.

Get it on Google Play iOS coming soon

Free. No ads. Open source.

Writing cards is the slow part of flashcards. An AI is good at it: it can turn a chapter, a word list, lecture slides or a TV episode into clean question and answer pairs in seconds. Loopky lets the AI go one step further and put the deck straight into the app.

What you can ask for

  • "A Japanese deck with the vocabulary from the first season of Naruto."
  • "The 200 most common French verbs, with an example sentence each, French to English, with audio on."
  • "Cloze cards from these pharmacology lecture notes."
  • "Every country in Africa and its capital, with a flag image."
  • "Convert this Anki file to a Loopky deck."

The prompt

Copy this into your AI agent, fill in the topic, and let it run. It installs the tool if needed, logs in (you approve with a QR code in Pubky Ring), writes the cards, checks them, and publishes.

Build me a Loopky flashcard deck with the Loopky CLI.

Topic: <WHAT I WANT TO LEARN>
Cards: <HOW MANY>

Steps:
1. Install the CLI if it is missing:
   curl -fsSL https://github.com/jvsena42/loopky/releases/latest/download/install.sh | sh
   Windows: irm https://github.com/jvsena42/loopky/releases/latest/download/install.ps1 | iex
2. Read the command surface first: loopky commands --json
3. Log in: loopky login
4. Write the cards to cards.tsv, one card per line: front <TAB> back
5. Check: loopky deck create --title "<TITLE>" --from-file cards.tsv --dry-run --json
6. Publish: loopky deck create --title "<TITLE>" --tag <TOPIC> --from-file cards.tsv
   Language deck: add --front-lang en-US --back-lang es-ES --listen --speak

The full, always current version is on the home page with a copy button.

Why it is safe to hand to an agent

  • Every command speaks JSON with --json, so the agent reads results instead of guessing.
  • Dry runs. --dry-run shows what would be written before anything is.
  • Narrow permissions. The CLI manages decks and cards. It can never post, follow people, or edit your profile.
  • You approve the login on your phone. The agent never sees your key.

Where it runs

One file, no Java, no setup. Linux (x86_64), macOS (Apple Silicon), Windows (x86_64), plus Homebrew, a .deb package and Docker. Commands cover decks (list, create, show, edit, delete), cards (list, add, edit, remove), import for TSV and Anki .apkg files, trending tags and batch operations. Read the CLI docs.

Then study it on your phone

The deck shows up in the Loopky app, scheduled with spaced repetition. Language decks can read cards aloud and check your pronunciation. Check AI written cards for mistakes, especially for medicine, law or anything you will be examined on.

Questions

Can ChatGPT or Claude make flashcards for me?

Yes. Any AI agent that can run shell commands can use the Loopky CLI to write cards and publish a deck. Give it the prompt on this page and your topic.

Do I need to know how to code?

No. You paste a prompt into an AI agent that has a terminal, such as Claude Code, ChatGPT with a shell, or Gemini CLI. The agent runs the commands.

Can the AI import my Anki decks?

Yes. loopky import deck.apkg imports an Anki package, and --dry-run shows the result first.

What can the CLI not do?

It cannot post, follow people or edit your profile. It only manages your decks and cards.
