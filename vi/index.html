Để AI của bạn dựng bộ thẻ

Hãy nói với AI bạn muốn học gì, từ bộ phim bạn mê đến buổi phỏng vấn tuần sau, hoặc đưa luôn ghi chú của bạn. Chọn một ý tưởng, sửa theo ý bạn rồi dán vào Claude, ChatGPT, Gemini hay agent bạn vẫn dùng.

  • Đưa gì cũng được: PDF, slide, bảng tính hay ảnh chụp ghi chú.
  • Chạy ngay trong ứng dụng AI bạn đang dùng, trên máy tính hay trình duyệt.
  • Bạn duyệt đăng nhập trên điện thoại, và nó chỉ đụng đến bộ thẻ của bạn.

Bạn dùng Claude Code hay Codex?

Cài plugin Loopky một lần. Sau đó chỉ cần yêu cầu flashcard: plugin biết mọi bước, và trên Claude Code bản web, nó tự cài CLI.

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky

Bắt đầu từ một ý tưởng

Khi sao chép sẽ kèm các bước cài đặt, để AI cài Loopky, viết thẻ và đăng bộ thẻ.

Xem toàn bộ prompt 
Build me a Loopky flashcard deck with the Loopky CLI.

What I want:
Một bộ thẻ tiếng Nhật với 40 từ và câu trong mùa đầu của Naruto. Kanji ở mặt trước, cách đọc và nghĩa ở mặt sau.

Use the loopky skill from the Loopky plugin for Claude Code. It installs with:
   /plugin marketplace add jvsena42/loopky
   /plugin install loopky@loopky
Not installed? Read the skill and follow it:
   https://github.com/jvsena42/loopky/blob/main/plugins/loopky/skills/loopky/SKILL.md
   Its CLI installer is published with each release:
   https://github.com/jvsena42/loopky/releases/latest/download/install.sh
   Windows: https://github.com/jvsena42/loopky/releases/latest/download/install.ps1
Mở trong

Claude Code và Cursor mở ra với prompt đã điền sẵn. Codex và Jules mở trống: prompt đã được sao chép, bạn chỉ cần dán vào.
