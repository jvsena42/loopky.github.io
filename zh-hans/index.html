AI 记忆卡制作

让你的 AI 来建卡组

告诉你的 AI 想学什么，从追的剧到下周的面试都行，也可以直接把笔记交给它。选一个点子，改成你想要的，贴给 Claude、ChatGPT、Gemini 或你常用的智能体。

  • 什么都能交给它：PDF、幻灯片、表格或笔记照片。
  • 在你常用的 AI 应用里就能用，电脑或浏览器都行。
  • 登录由你在手机上确认，它只动你的卡组。

在用 Claude Code 或 Codex？

安装一次 Loopky 插件，之后直接要抽认卡就行：它知道每一步，在网页版 Claude Code 中还会自动安装 CLI。

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky
