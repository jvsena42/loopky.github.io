平板和电脑

平板上是双栏布局，电脑上有命令行工具批量处理卡组。

为大屏幕而做

在平板上，Loopky 使用真正的双栏布局：今天的复习队列在卡组旁边，卡组在它的卡片旁边。现在支持 Android 平板，iOS 应用推出后支持 iPad。

在电脑上管理卡组

Loopky 命令行工具可在 Windows、macOS 和 Linux 上运行。

  • 创建、编辑和删除卡组
  • 批量添加、编辑和删除卡片
  • 从本地导入 .apkg 和 TSV 文件
  • 写成脚本，或交给 AI 智能体来做
loopky
# Bring a whole Anki deck across
$ loopky import deck.apkg --dry-run --json
$ loopky import deck.apkg --title "Pharmacology"
# Or build one from a spreadsheet
$ loopky deck create --title "Verbs" --from-file cards.tsv
$ loopky deck list --json

一分钟搬走一个卡组

在 Anki 中把卡组导出为带媒体的 .apkg。用 Loopky 打开，选好正面和背面字段。只有一份列表？直接粘贴。

常见问题

Loopky 能完全取代 Anki 吗？

对大多数学习者来说可以。如果你依赖音频文件、LaTeX、自定义卡片模板或 FSRS，请先确认一下。

Loopky 使用 FSRS 吗？

不使用。每个评分按钮有固定的间隔，由你设置，范围是 1 到 365 天。

是免费的吗？

是的。没有广告，没有订阅，并以 MIT 许可开源。

有 iPhone 应用吗？

Loopky 现在支持 Android。iOS 应用已经做好，即将推出。
