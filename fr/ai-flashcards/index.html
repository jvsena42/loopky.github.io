Laissez votre IA écrire les flashcards

Donnez à Claude, ChatGPT ou Gemini un sujet ou un fichier. L’IA écrit les cartes et publie le paquet sur votre téléphone.

loopky
# Your AI agent runs these for you
$ loopky login
$ loopky deck create --title "Spanish verbs" \
    --from-file cards.tsv --dry-run --json
$ loopky deck create --title "Spanish verbs" \
    --tag spanish --from-file cards.tsv \
    --front-lang es-ES --back-lang en-US --listen --speak

Puis révisez-le sur votre téléphone

Le paquet apparaît dans Loopky, prêt pour la répétition espacée, avec l’audio pour les paquets de langues. Relisez les cartes écrites par l’IA pour repérer les erreurs.

Rien à installer pour vous

Votre IA installe Loopky elle-même, sur Windows, macOS ou Linux, même quand vous discutez avec elle dans le navigateur. Homebrew, un paquet .deb et Docker marchent aussi.

Questions

Faut-il savoir coder ?

Non. Collez le prompt dans votre IA, ajoutez votre sujet ou votre fichier, et elle fait chaque étape toute seule. Ça marche dans les apps de chat IA et avec des agents comme Claude Code, Codex et Gemini CLI.

Existe-t-il un plugin pour Claude Code ou Codex ?

Oui. Dans Claude Code, lancez /plugin marketplace add jvsena42/loopky, puis /plugin install loopky@loopky. Dans Codex, lancez codex plugin marketplace add jvsena42/loopky, puis codex plugin add loopky@loopky. Ensuite, demandez simplement des flashcards : le plugin connaît chaque étape, vous n'avez besoin d'aucun prompt.

L’IA peut-elle importer mes paquets Anki ?

Oui. loopky import deck.apkg importe un paquet Anki, et --dry-run montre d’abord le résultat.

Que ne peut pas faire l’outil ?

Il ne peut pas poster, suivre des personnes ou modifier votre profil. Il gère seulement les paquets et les cartes.

Est-ce que ça marche dans Claude Code sur le web ou dans Codex ?

Oui, dès que votre sandbox peut joindre les hôtes de Loopky. Aucun des deux ne les autorise par défaut. Demandez à l'agent de lancer loopky doctor : il liste les hôtes et indique où les ajouter. Dans Codex, laissez désactivée l'option GET/HEAD/OPTIONS uniquement. Avec le plugin, Claude Code sur le web installe la CLI tout seul. Un sandbox qui inspecte le TLS fonctionne dès que son certificat est indiqué avec SSL_CERT_FILE.

Quels fichiers peut-elle transformer en cartes ?

Tout ce que votre IA sait lire : PDF, fichiers Word et PowerPoint, tableurs, photos de notes, sous-titres et pages web.
