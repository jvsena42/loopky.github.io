Bau den Stapel, wie du willst

Tipp die Karten ein, füg eine Liste aus einer Tabelle ein, importiere eine Anki-Datei, oder lass eine KI sie schreiben.

Dein Profil ist dein Kurs

Dein Profil listet jeden Stapel, den du veröffentlichst. So reicht ein Link für das ganze Halbjahr.

Fragen

Brauchen Schüler eine E-Mail-Adresse?

Nein. Sie melden sich mit einem Pubky-Schlüssel an oder legen ein Konto in der App an.

Kann ich den Fortschritt meiner Schüler sehen?

Nein. Der Fortschritt gehört allein den Schülern, und es gibt kein Dashboard für Lehrkräfte.

Können Schüler mit iPhone mitmachen?

Sie können die Stapelseite schon jetzt im Browser öffnen und damit lernen, sobald die iOS-App da ist.
