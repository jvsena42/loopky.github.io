    --from-file cards.tsv --dry-run --json
$ loopky deck create --title "Spanish verbs" \

Fragen

Muss ich programmieren können?

Nein. Füg den Prompt in deine KI ein, gib dein Thema oder deine Datei dazu, und sie erledigt jeden Schritt selbst. Das klappt in KI-Chat-Apps und mit Agenten wie Claude Code, Codex und Gemini CLI.

Gibt es ein Plugin für Claude Code oder Codex?

Ja. In Claude Code führst du /plugin marketplace add jvsena42/loopky und dann /plugin install loopky@loopky aus. In Codex führst du codex plugin marketplace add jvsena42/loopky und dann codex plugin add loopky@loopky aus. Danach bittest du einfach um Karteikarten: Das Plugin kennt jeden Schritt, du brauchst keinen Prompt.

Kann die KI meine Anki-Stapel importieren?

Ja. loopky import deck.apkg importiert ein Anki-Paket, und --dry-run zeigt vorher das Ergebnis.

Was kann das Tool nicht?

Es kann nicht posten, Leuten folgen oder dein Profil ändern. Es verwaltet nur Stapel und Karten.

Funktioniert es in Claude Code im Web oder in Codex?

Ja, sobald deine Sandbox die Hosts von Loopky erreicht. Keine der beiden lässt sie standardmäßig durch. Lass den Agenten loopky doctor ausführen: Es listet die Hosts auf und sagt, wo du sie einträgst. In Codex die Option „nur GET/HEAD/OPTIONS“ ausgeschaltet lassen. Mit dem Plugin installiert Claude Code im Web die CLI selbst. Eine Sandbox, die TLS prüft, funktioniert, sobald ihr Zertifikat mit SSL_CERT_FILE angegeben ist.

Welche Dateien kann sie in Karten verwandeln?

Alles, was deine KI lesen kann: PDFs, Word- und PowerPoint-Dateien, Tabellen, Fotos von Notizen, Untertitel und Webseiten.
