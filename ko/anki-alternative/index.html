컴퓨터에서 덱 관리

Loopky 명령줄 도구는 Windows, macOS, Linux에서 실행됩니다.

  • 덱 만들기, 수정, 삭제
  • 카드를 한꺼번에 추가, 수정, 삭제
  • 디스크의 .apkg와 TSV 파일 가져오기
  • 스크립트로 돌리거나 AI 에이전트에게 맡기기
loopky
# Bring a whole Anki deck across
$ loopky import deck.apkg --dry-run --json
$ loopky import deck.apkg --title "Pharmacology"
# Or build one from a spreadsheet
$ loopky deck create --title "Verbs" --from-file cards.tsv
$ loopky deck list --json

1분이면 덱 이전

Anki에서 덱을 미디어 포함 .apkg로 내보내세요. Loopky에서 열고 앞면과 뒷면 필드를 고르면 됩니다. 목록만 있다면 붙여넣으세요.

자주 묻는 질문

Loopky가 Anki를 완전히 대신할 수 있나요?

대부분의 학습자에게는 그렇습니다. 오디오 파일, LaTeX, 사용자 카드 템플릿, FSRS에 의존한다면 먼저 확인하세요.

Loopky는 FSRS를 쓰나요?

아니요. 평가 버튼마다 직접 정하는 고정 간격이 있고, 1~365일 사이로 설정합니다.
