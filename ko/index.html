AI 플래시카드 메이커

AI에게 덱을 맡기세요

좋아하는 드라마부터 다음 주 면접까지, 배우고 싶은 걸 AI에게 말하거나 노트를 그대로 건네 보세요. 아이디어를 고르고 내 식으로 고친 뒤 Claude, ChatGPT, Gemini나 평소 쓰는 에이전트에 붙여 넣으면 됩니다.

  • PDF, 슬라이드, 스프레드시트, 노트 사진까지 무엇이든 건네세요.
  • 평소 쓰는 AI 앱에서, 컴퓨터든 브라우저든 작동합니다.
  • 로그인은 휴대폰에서 승인하고, 건드리는 건 내 덱뿐입니다.

Claude Code나 Codex를 쓰나요?

Loopky 플러그인을 한 번 설치하세요. 그다음엔 플래시카드를 요청하기만 하면 됩니다. 모든 단계를 알고 있고, 웹용 Claude Code에서는 CLI도 직접 설치합니다.

Claude Code

/plugin marketplace add jvsena42/loopky
/plugin install loopky@loopky

Codex

codex plugin marketplace add jvsena42/loopky
codex plugin add loopky@loopky
